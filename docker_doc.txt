Docker: Docker is an open-source platform designed to automate the deployment, scaling, 
and management of applications within lightweight, portable containers. 
Containers encapsulate an application and its dependencies into a single package, 
ensuring that it runs consistently across different computing environments.

Steps to deploy:
-write a application code
-build a docker image
-deploy docker container on server

Containerization in Docker is the process of packaging an application and 
its dependencies into a single, lightweight, 
and portable container that can run consistently across different computing environments. 
Docker containers encapsulate everything an application needs to run, 
including the code, runtime, libraries, environment variables, and configuration files.
